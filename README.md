## 🔍 Обзор

Этот репозиторий содержит серию практических работ по глубокому обучению, выполненных в рамках университетского курса. Все задания реализованы с использованием фреймворка **PyTorch** и охватывают широкий спектр тем: от базовых архитектур нейронных сетей до современных подходов в области метрического обучения и анализа временных рядов.

Проекты включают как классические задачи компьютерного зрения (классификация изображений), так и более специализированные направления — обучение эмбеддингов с Triplet Loss и обработку последовательных данных с использованием рекуррентных нейросетей.

## 📊 Результаты

### Ключевые достижения

| Задача | Метрика | Результат |
|--------|---------|-----------|
| **CNN на CIFAR-10** (Improved) | Test Accuracy | **86.2%** |
| **CNN на CIFAR-10** (Baseline) | Test Accuracy | 74.7% |
| **Triplet Loss (MNIST)** | Качество кластеризации | Визуально разделимые кластеры |

### Дополнительные наблюдения

- **MLP**: Подбор learning rate и L2-регуляризации критически влияет на обобщающую способность модели.
- **CNN с Residual-связями**: Дает значительный прирост качества (~+11.5% к baseline).
- **Triplet Loss**: Эмбеддинги MNIST формируют четкие кластеры, визуализация t-SNE подтверждает эффективность метрического обучения.
- **LSTM для HAR**: Модель успешно классифицирует временные ряды с сенсорных устройств.
